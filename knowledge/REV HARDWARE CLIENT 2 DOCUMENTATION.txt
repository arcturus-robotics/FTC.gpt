REV HARDWARE CLIENT 2 DOCUMENTATION

Overview
The REV Hardware Client 2 (RHC2) is software designed by REV Robotics to make managing REV devices easier for the user. This client automatically detects connected devices, downloads the latest software for those devices, and allows for seamless updating of the devices.

Feature Summary
- Automatically detect supported devices when connected via USB
- One-click update of all software on connected devices
- Pre-download software updates without a connected device
- Back up and restore user data from supported devices
- Auto-update to the latest version of the REV Hardware Client 2

Installation Instructions
1. Download the REV Hardware Client 2 Installer
2. Run the Installer
3. Run the REV Hardware Client 2 from the applications menu or a desktop shortcut

System Requirements
Operating Systems:
- Windows 11, Windows 10 (version 1709 - October 2017) or newer
- macOS 15 (Sequoia) or newer
- Linux: Ubuntu 24.04 / Debian 12 or newer
Processor: 64-bit
RAM: 4 GB minimum

Supported Devices
- REV Control Hub (REV-31-1595)
- REV Driver Hub (REV-31-1596)
- REV Expansion Hub (REV-31-1153)
- Android Phones
- REV SPARK MAX (REV-11-2158)
- REV SPARK Flex (REV-11-2159)
- REV Power Distribution Hub (REV-11-1850)
- REV Pneumatic Hub (REV-11-1852)
- REV Servo Hub (REV-11-1855)
- REV MAXSpline Encoder (REV-11-9008)
- A301 (REV-41-2714)
- Generic CAN Devices

REV Device Requirements
REV devices must be running Firmware Versions 26.x.x or newer to be compatible with REV Hardware Client 2. Devices with 2025 firmware and below will need to be updated to 2026 firmware via Recovery Mode before use. If your REV device shows up in the REV Hardware Client 2 as an "Outdated REV Device", follow the Recovery Mode instructions to update its firmware.

TROUBLESHOOTING - REV HARDWARE CLIENT 2

Note
Please note that you cannot update the original Hardware Client to Hardware Client 2. You must install Hardware Client 2 separately, as they are completely different applications. While they can be installed simultaneously, it is not recommended to have both open at the same time.

Device Is Not Visible
If you don't see all of the devices that you expect to see, follow these steps:
- Make sure that you are connected to the Internet, so that Windows can download the necessary drivers.
- Disconnect the device from the computer and then reconnect it.

Mac Users and Recovery Mode
If you plan on using RHC2 on a macOS machine, please note that recovery mode devices will only show up on Mac if the app is copied into /Applications.

SPARK MAX Motor Controller
- Make sure that the SPARK MAX is not being used by another application, such as the REV SPARK MAX Client.
- Unplug the SPARK MAX from the computer and plug it back in.

Firmware Compatibility
To use your device with RHC2, you must have 2026 firmware (v26.x.x). Devices with 2025 firmware or lower must be updated to 2026 via recovery mode. SPARKs can be updated via CAN with RHC2 if the bridge device (the device connected to USB) is updated to firmware 2026.

RECOVERY MODE - REV HARDWARE CLIENT 2

Overview
Sometimes, when updating the firmware on an ION Control System Device, it is possible for the process to be interrupted or for the firmware to be corrupted by a bad download or other type of interruption in data transfer. In this state, the Status LED will be dark or dim and the device will fail to operate. There is a built-in recovery mode that can force your device to accept new firmware even if the controller seems to be bricked.

Important Note
Performing this procedure will erase all data and settings on the device. You will need to reconfigure your device after performing recovery mode.

Materials Needed
- A small tool, like a straightened paper clip or a SIM card removal tool, to press the Mode Button
- Data-capable USB-C to USB-A cable
- Computer with the REV Hardware Client 2 installed and updated to the latest version

Recovery Mode Steps
1. With the Device powered off, press and hold the Mode Button.
2. While still holding the Mode Button, connect the Device to the computer using the USB-C cable. The Status LED will not illuminate (this is expected).
3. With the REV Hardware Client 2 running on the computer, wait a few seconds for the audible tone or icon for the device to be recognized, then release the Mode Button. No lights will be present on the device during this stage of the process (this is expected).
4. Select the DFU Device Bootloader from the list of Connected Devices within the REV Hardware Client 2 window.
5. From the Device Type dropdown menu, choose the device name that matches the type of device you are attempting to recover. Note: It is possible to install incorrect firmware on your device.
6. After the proper Device Type has been selected, the Current Firmware Version Dropdown menu will automatically select the most up-to-date firmware. If you wish to install a different version of firmware, select it from this menu. (Firmware must be version 26.x.x or newer to work with REV Hardware Client 2).
7. Wait for the software update to complete.
8. Power cycle your device (unplug and plug in USB-C), click on the device's icon, and then clear any sticky faults that may show.


MAKE IT SPIN! - REV HARDWARE CLIENT 2

Power On
Now that the device is wired and connections are checked, power on the robot. The SPARK Flex should slowly blink Magenta for a new device. If the LED is dark or displays a different blink pattern, refer to the Status LED guide. If using a brushed motor, a sensor error may appear initially until configured.

Connect to the SPARK Flex
If the SPARK Flex is not visible in the client, ensure it is not in use by another application, then disconnect and reconnect its USB connection.

Basic Setup and Configuration
Before modifying parameters, assign a unique CAN ID between 1 and 63 to the device. Setting a unique CAN ID refreshes the interface to unlock other parameter configurations. Ensure every device on your CAN network has a unique ID and is labeled accordingly.

Set the Motor Type
- NEO / NEO 550: Set motor type to REV NEO Brushless and sensor type to Hall Effect. Verify the LED blinks Magenta or Cyan.
- Sensor Fault: If a Sensor Fault blink code appears, check that the encoder cable is securely plugged in.

Limiting Current
To prevent motor damage from high current, use both an appropriately rated circuit breaker and the SPARK Flex's Smart Current Limit feature (defaulted at 80A).
Suggested Current Limits:
- NEO (REV-21-1650): 40A - 60A
- NEO 550 (REV-21-1651): 20A - 40A

Save the Settings
Click the Persist Parameters button at the bottom right of the page to save configurations across power cycles.

Spin the Motor
1. Ensure all components are secure and safe, and the CAN ID is set to a non-zero value.
2. Keep the CAN cable disconnected from the roboRIO during testing (the client will not run motors if a roboRIO is detected on the bus).
3. Open the Run tab, keep default settings, and click Run Motor.
4. Slowly advance the setpoint slider. Green blinking indicates forward motor rotation; red blinking indicates reverse rotation.

SWERVE CALIBRATION - REV HARDWARE CLIENT 2

Prerequisites & Setup
1. Verify you have completely assembled your MAXSwerve or EasySwerve Module and have the Steering Motor's SPARK Flex or SPARK MAX connected to the Module's Through Bore Encoder.
2. Install and open the latest version of the REV Hardware Client.
3. Connect the Steering Motor's SPARK Motor Controller directly to your computer via the included USB-C to USB-A cable.
4. Select the Steering SPARK from the list of Connected Devices and navigate to the Update Tab to verify your Firmware is up to date.
5. Ensure the Steering SPARK is still selected, then navigate to Absolute Encoder under the Utilities Tab.

EasySwerve Calibration
1. Insert a 1/8in or 3mm Hex Key into the calibration hole on the top of the EasySwerve Module until you feel the Hex Key reach the azimuth gear inside of the top cover.
2. Rotate the module's wheel manually while applying light pressure to the hex key until it slots into the alignment pocket. The Hex key will travel about 1/4in further into the swerve module when it has aligned.
3. Click the Zero Encoder button to calibrate the zero position of the absolute encoder to this position.
