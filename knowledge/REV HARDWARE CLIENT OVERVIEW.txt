REV HARDWARE CLIENT OVERVIEW

End of Life Notice
REV Hardware Client has reached end of life and is no longer supported. Please use REV Hardware Client 2 for continued updates and support.

Overview
The REV Hardware Client (RHC) is software designed to make managing REV devices easier for the user. This Client automatically detects connected device(s), downloads the latest software for those device(s), and allows for seamless updating of the device(s).

Downloads & System Requirements
- Current Version: REV Hardware Client - Version 1.7.7
- Offline Installers: FTC Offline Installer / Offline Installer (All available software)
- OS Requirement: As of April 12, 2024, Windows 10 or later is required for the latest version of the REV Hardware Client. Version 1.6.4 is required for older versions of Windows.

Feature Summary
- Automatically detect supported devices when connected via USB
- Connect a REV Control Hub via Wi-Fi
- One-click update of all software on connected devices
- Pre-download software updates without a connected device
- Back up and restore user data from supported devices (REV DUO: Control Hub, REV ION: SPARK Flex & SPARK MAX)
- Install and switch between DS and RC applications on Android Devices
- Access the Robot Control Console on the Control Hub
- Auto-update to the latest version of the REV Hardware Client
- Display devices connected via RS485

Supported Devices
- REV Control Hub (REV-31-1595)
- REV Expansion Hub (REV-31-1153)
- REV Driver Hub (REV-31-1596)
- REV Servo Hub (REV-11-1855)
- Android Device via ADB
- Generic CAN Devices
- Legacy compatible (2025 and earlier firmware):
  - REV SPARK Flex (REV-11-2159)
  - REV SPARK MAX (REV-11-2158)
  - REV Power Distribution Hub (REV-11-1850)
  - REV Pneumatic Hub (REV-11-1852)

NAVIGATING THE CLIENT - REV HARDWARE CLIENT (LEGACY)

Overview
The REV Hardware Client has three tabs to manage different features of the Client:
- Hardware Tab: Manages supported hardware devices.
- Downloads Tab: Downloads supported device software for updating when offline.
- About Tab: Contains information on supported devices, updating the REV Hardware Client, and issue reporting.

Hardware Tab
The Hardware Tab is where supported hardware devices are managed. When opening the REV Hardware Client, the Hardware Tab is displayed by default.

No Hardware Detected:
1. Scan for Devices - When supported REV hardware is connected to a Windows PC, the Client automatically scans for new devices. You can click Scan for Devices if the device did not automatically populate.
2. Check for Updates - Checks for any available updates for the REV Hardware Client.
3. Navigation - Three tabs located at the top allow navigation between features.

Hardware Detected:
Connecting supported hardware to a Windows PC with the REV Hardware Client running will automatically scan and add the devices to the Hardware Tab.
- Supported Hardware - Each type of supported hardware will appear. Clicking on a device opens its Device Menu.

Device Menu:
1. Device Menu Tabs - Swaps between available tabs for the selected device. All devices have an Updates Tab. The Control Hub also includes a Program and Manage Tab (for the Robot Control Console) and a Backup and Restore Tab (for configuration files, Blocks, and Java code).
2. Out of Date Warning - Displays indicators when any software component on the device is out of date.
3. Download and Install - Buttons under each update type to download and install updates.
4. Update All - Updates all software items for all connected devices simultaneously.

Downloads Tab
The Downloads Tab is where downloaded software files are managed. The latest software updates can be downloaded without a hardware device connected.
1. Downloaded Update Files - View previously downloaded software versions, check release notes, or delete files from the local machine.
2. Available Update Files - Displays the latest software versions available for download along with release notes and a download button.

About Tab
The About Tab is where the REV Hardware Client itself is managed.
1. Check for Updates - Displays the current version of the REV Hardware Client and checks for client software updates.
2. Supported Devices - Lists all currently supported devices for the installed version of the REV Hardware Client.

TROUBLESHOOTING - REV HARDWARE CLIENT (LEGACY)

Device Is Not Visible
If you don't see all of the devices that you expect to see, follow these steps:
- Make sure that you are connected to the Internet, so that Windows can download the necessary drivers
- Disconnect the device from the computer and then re-connect it
- Click the "Scan for Devices" link in the bottom-right corner of the Hardware tab

Control Hubs Connected via USB
- Make sure that the Control Hub is plugged in via USB-C, not Mini USB
- Make sure the Control Hub has had a chance to finish starting up, and that its light is green
- Unplug the Control Hub from the computer and plug it back in

Control Hubs Connected via WiFi
- Make sure that the Control Hub is running version 5.5 or later of the Robot Controller app
- Make sure the Control Hub has had a chance to finish starting up, and that its light is green
- Make sure that you are currently connected to the Control Hub's WiFi network
- Try rebooting the Control Hub. Re-connect to its WiFi network after its light turns green
- Plug the Control Hub in via USB instead

Expansion Hubs Connected to a Control Hub
- Make sure that the Expansion Hub is in the active configuration file
- Make sure that the Control Hub is running version 5.5 or later of the Robot Controller app

Android Phones
- Make sure that USB debugging is enabled in the Developer Options
  - If Developer Options is missing, enable it by tapping the Build number 7 times on the About screen in Settings
- Unplug the phone from the computer and plug it back in, then accept the USB debugging prompt
- Make sure that the ADB driver for your Android phone is installed (e.g., Motorola Device Manager for Motorola phones)

SPARK MAX Motor Controller
- Make sure that the SPARK MAX is not being used by another application, such as the REV SPARK MAX Client
- Unplug the SPARK MAX from the computer and plug it back in


CONTROL HUB - CONNECTING VIA USB (REV HARDWARE CLIENT)

Steps to Connect:
1. Power on the Control Hub by plugging the 12V Slim Battery (REV-31-1302) into the XT30 connector labeled "BATTERY" on the Control Hub.
2. The Control Hub is ready to connect with a PC when the LED turns green. (Note: The light blinks blue every ~5 seconds to indicate that the Control Hub is healthy).
3. Plug the Control Hub into the PC using a USB-A to USB-C Cable (REV-11-1232).
4. Startup the REV Hardware Client. Once the Hub is fully connected, it will show up on the front page of the UI under the Hardware Tab. Select the Control Hub.

USING THE LOG VIEWER - REV HARDWARE CLIENT (LEGACY)

Overview
Log files provide indicators of Control Hub or Expansion Hub status during system events. The REV Hardware Client Log Viewer helps parse Robot Controller, Wi-Fi, and Updater logs using filters, tags, and search functions.

Accessing the Log Viewer
1. Open the REV Hardware Client and navigate to the Utilities Tab.
2. Select and open log files for connected devices or log files previously downloaded onto the computer.

Parsing the Logs
- Time Synchronization: Ensure the Driver Hub or Driver Station phone is set to the correct date and time before recording logs so events align accurately across log files.
- Matches: When selecting a connected device, choose standard logs or Matches (log segments specific to an individual op mode run).

Log Type Filters
1. Errors: Triggered when system actions fail to execute (e.g., code errors, configuration/wiring issues, camera calibration failure, or OnBot Java build failures).
2. Warnings: Non-fatal events that may cause unexpected behavior (e.g., app version mismatches or low power warnings).
3. Info: Information on normal system milestones, such as when a program is initialized, started, or stopped.
4. Fatal: Severe system-level failures. Frequent fatal logs warrant sending diagnostic data to REV support along with LED status descriptions.
5. Debug: Output from SDK debugging tools (filtered out by default).
6. Verbose: Detailed records of routine system behaviors not covered by other log types.

Running One SPARK Motor Controller
1. Connect your SPARK to the REV Hardware Client via USB-C (directly or through another device on the CAN network, such as the Power Distribution Hub). Open the Telemetry tab.
2. Select the target device from the left panel under Connected Hardware.
3. Select desired signals to plot (e.g., Voltage, Primary Encoder Position, Primary Encoder Velocity).
4. Click Start Graph, configure Mode (e.g., Percent) and Setpoint (e.g., 0.05), and click Run Motor.

Running Multiple SPARKs
1. Connect all SPARK devices, updated and wired via CAN, and connect the host USB-C device (e.g., Power Distribution Hub) to the PC. Open the Telemetry tab.
2. Select the first device and configure its signals.
3. Click the Run Multiple tab and check the box for each additional controller you want to run simultaneously (e.g., SPARK Flex and SPARK MAX).
4. Return to the device list, select the second controller, and choose its desired signals.
5. Under the Run Multiple tab, select Start Graph, set Mode and Setpoint (e.g., 0.03), and click Run Motor.

Safety & Troubleshooting Note
- roboRIO Lockout: USB control is disabled if a roboRIO is detected on the CAN bus while active. To clear the lockout, power cycle the SPARK controllers after disconnecting the roboRIO


RECOVERY MODE - REV HARDWARE CLIENT (LEGACY)

Notice
Those using REV ION products on REVLib 2026 or newer must use REV Hardware Client 2.

Overview
When updating firmware on an ION Control System Device, an interrupted transfer or bad download can cause the Status LED to remain dark or dim and the device to stop functioning. The built-in Recovery Mode forces the device to accept new firmware even if it appears bricked.
Note: Performing this recovery erases all data and settings on the device. Remember to persist/burn desired settings to flash after recovering the device.

Materials Needed
- Small tool (e.g., a straightened paper clip or SIM card removal tool) to press the Mode Button.
- Data-capable USB-C to USB-A cable.
- Windows PC with the REV Hardware Client installed and updated.

Recovery Steps
1. With the device powered off, press and hold the Mode Button.
2. While holding the Mode Button, connect the device to the PC using the USB-C cable (the Status LED will remain unlit, which is expected).
3. With the REV Hardware Client running, wait a few seconds until the device is recognized in recovery mode, then release the Mode Button.
4. Select the device in Recovery Mode from the REV Hardware Client window.
5. Under "Choose a Device type", select the firmware matching the device you are recovering (ensure the correct device type is selected).
6. Select the latest Firmware version from the dropdown menu and click Update.
7. Wait for the update process to complete.
8. Power cycle the device (unplug and replug the USB-C cable), click on the device icon, and clear any sticky faults.

SERVO HUB - REV HARDWARE CLIENT (LEGACY)

Connecting via USB
- Connect your Servo Hub to your computer with a USB-C cable.
- Open the REV Hardware Client application.
- The Client will automatically scan and connect to your Servo Hub.

Navigating the REV Hardware Client
The REV Hardware Client includes four primary tabs:
- Hardware Tab: Manage supported hardware devices.
- Utilities Tab: View log files collected by the Control Hub or Driver Hub.
- Downloads Tab: Download supported device software for offline updating.
- About Tab: View supported devices, update the REV Hardware Client, and access troubleshooting information.

Basic Tab
1. CAN ID: Assigns the Servo Hub a CAN ID for identification over the CAN bus. Required for any configured Servo Hub; also serves as the Hub Address used with the Control Hub and Expansion Hub.
2. Servo Limits: Set angular limits for each servo port. Changes are automatically saved to the Servo Hub.
3. Disabled Behavior: Select the behavior of the Servo Hub when it is disabled through code.

Servo Tab
- Servo Controls: Run and test servos connected to the Servo Hub directly through the REV Hardware Client.

Update Tab
1. Download Latest Firmware: Downloads the latest firmware files onto the local machine.
2. Update Firmware: Updates the selected device with the latest firmware.
3. Out-of-date Firmware Warning: Alerts when new firmware versions are available.
